# Iris Dataset Analysis

## Project Description

This project analyzes the Iris dataset using Python and Pandas.
The project was created using uv, and the analysis was performed in a Jupyter Notebook.

## Project Setup

Install uv and run the following commands inside the project directory:

```bash
uv sync
uv run jupyter notebook
## Findings

- The dataset contains 150 rows and 5 columns.
- The dataset has no missing values.
- The dataset contains 3 flower species.
- The analysis includes descriptive statistics and group means.
- The dataset was filtered and sorted.
- Scatter and bar charts were created to visualize the data.
- The results were exported to CSV files.

## Output Files

- output/species_summary.csv
- output/filtered_iris.csv
